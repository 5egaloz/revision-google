# ¿Tu negocio aparece en Google?

Página de una sola pantalla: el dueño de un negocio deja el nombre de su negocio y su
WhatsApp, y le llega el aviso al instante para revisarle a mano cómo se ve en Google.

Es el paso de entrada de Becker.IA: no cuesta nada, abre conversación y deja el resultado
medido.

- **En vivo:** https://5egaloz.github.io/revision-google/
- Los datos se envían a un webhook de n8n propio. No hay analítica ni terceros.
